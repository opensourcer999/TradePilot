TradePilot for macOS

Installation: drag TradePilot.app into the "Applications" folder.

First start: the app is not notarized by Apple. Right-click TradePilot.app > "Open" > "Open".
This is only needed the first time. If it is still blocked: System Settings > Privacy & Security >
"Open Anyway".

Data: ~/Library/Application Support/TradeWorkspace (trades, templates, settings, log). It is not part of the
package and is kept when the app is deleted.

Requirements: Interactive Brokers TWS or Gateway on this computer with the API enabled (port 7497 = paper).
